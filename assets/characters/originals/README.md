# Original AI Character Images

This folder is an immutable archive of AI-generated source images **before runtime background removal, resizing, baseline alignment, or sprite cleanup**.

- `player_ink_fighter/` — player source references and sample frame outputs.
- `bot_crimson_rival/` — approved black-and-crimson rival source references and sample frame outputs.

Do not load this folder in the release build. Keep these files so later frame cleanup can be traced back to the original generation. The prompt pack and character art bible live in `docs/product/`.
