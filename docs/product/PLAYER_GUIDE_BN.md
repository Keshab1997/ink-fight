# INK FIGHT — Player Guide (বাংলা)

## Game সম্পর্কে

**INK FIGHT: Doodle Combat** একটি landscape mobile fighting game। এখানে black-and-white ink art, doodle fighter এবং ছোট, skill-based match থাকবে। প্রথমে Player বনাম Bot mode থাকবে। পরের ধাপে আলাদা ফোনে online 1v1 যোগ হবে। একই ফোনে দুইজনের mode থাকবে না।

## কীভাবে খেলবে

1. Game খুলে Splash Screen শেষ হওয়া পর্যন্ত অপেক্ষা করো।
2. Main Menu থেকে **Bot Fight** চাপো।
3. Fighter এবং difficulty বেছে নাও।
4. Tutorial hint দেখে **Ready** চাপো।
5. বাম পাশে movement এবং ডান পাশে attack/control button ব্যবহার করো।

## জেতার নিয়ম

Timer শেষ হওয়ার আগে opponent-এর health শূন্য করতে হবে। Timer শেষ হলে যার health বেশি থাকবে সে জিতবে। একই health হলে build অনুযায়ী draw হতে পারে।

## Control layout

- **বাম পাশে:** movement joystick বা directional control
- **ডান পাশে:** punch/attack, heavy attack বা kick, block, jump/dodge
- **উপরে:** Player এবং opponent health bar, সঙ্গে timer

## Online 1v1

Online 1v1 আলাদা দুইটি ফোনে হবে। Match শুরু করার আগে connection check থাকতে পারে। Disconnect হলে screen-এর reconnect message অনুসরণ করো এবং countdown চলার সময় game বন্ধ করো না।

## Fair play

Modified app, script, cheat, network manipulation বা exploit ব্যবহার করা যাবে না। অন্য player-কে গালি, ভয় দেখানো বা harassment করা যাবে না। Abuse বা cheating হলে match বাতিল, temporary restriction অথবা account action হতে পারে।

## Ads ও reward

যদি ad চালু থাকে, fight চলার সময় ad দেখানো হবে না। Rewarded ad সম্পূর্ণ optional হবে এবং ad দেখার আগে reward কী তা লেখা থাকবে। কোনো unofficial “unlimited coin” version ব্যবহার করো না।

## সমস্যা হলে

- Control দেরি করলে background app বন্ধ করে আবার চেষ্টা করো।
- Connection warning হলে stable network ব্যবহার করো।
- Reward না পেলে result screen-এর screenshot নিয়ে support-এ জানাও।
- কোনো player খারাপ আচরণ করলে report এবং block option ব্যবহার করো।
